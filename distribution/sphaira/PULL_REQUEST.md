Add LunaNX, an unofficial native Amazon Luna streaming client for Nintendo
Switch homebrew, to the GitHub download browser.

The proposed file is `assets/romfs/github/LunaNX.json`, following the existing
repository-URL catalog entry format. The project is GPL-3.0-or-later and its
GitHub release provides an SD-root install ZIP with
`switch/LunaNX/LunaNX.nro`, matching source, notices and checksums.

LunaNX requires full application memory/title takeover and the user's own Luna
account/game access. This is a prepared PR description; submit only after the
public repository and release asset URLs are live. Maintainer acceptance and
installation through Sphaira have not yet been verified.
