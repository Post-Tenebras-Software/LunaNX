# Security reports

Report vulnerabilities privately to **posttenebrassoftware@proton.me** before
posting details publicly. Include the LunaNX version, affected behavior and
reproduction steps using synthetic data where possible.

Do not send passwords, Amazon access/profile/play tokens, saved `login.bin`
files, complete HAR captures or SDP. Logs supplied to public issues should
contain only sanitized application stages and numeric status fields.

Saved sign-in is encrypted for the Switch. Treat the app's SD-card data and
backups as private. Forgetting sign-in removes local remembered credentials;
Amazon device/account controls remain the place to revoke account access.

This is an unofficial client maintained by a small project. No response-time
or security-support guarantee is made.
